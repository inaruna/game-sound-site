// スライダー値（0〜1）を AudioMixer に渡す
public void SetVolume(float value)
{
    float dB = Mathf.Log10(Mathf.Max(value, 0.0001f)) * 20f;
    mixer.SetFloat("BGMVolume", dB); // 露出したパラメーター名
}

0は-80dB（Unity AudioMixerの最小値）として扱います。dB = 20 × log10(リニア値) で計算しています。0dBより大きい値（リニアで1超え）はAudioMixerでは使えますが、AudioSource.volume には使えません。

よくある質問

Unityの音量スライダーを線形のままミキサーに渡すとどうなりますか？

AudioMixerはdB単位なので、0〜1の値をそのまま渡すと0〜+1dBの範囲しか動かず、音量がほとんど変わりません。上のコードのように、20 × log10(値) でdBに変換してから渡します。

BGMのループがずれるのはなぜですか？

ループ長を秒で丸めると、サンプル単位でずれが出ます。サンプル数で指定し、書き出し時のサンプルレートとゲーム側の設定を合わせると防げます。

効果音はWAVとOGGのどちらがいいですか？

元の素材はWAVで用意し、Unityならインポート設定で、短い効果音はADPCM、BGMはVorbisに圧縮するのが一般的です。Godotでは効果音をWAV、BGMをOGGで入れるのが一般的です。容量は上のファイルサイズ計算で比べられます。
